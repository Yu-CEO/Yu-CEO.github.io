# 入口ページ（portal）

TikTok・LINEから来た人が、Yuの自己紹介と無料ツールの一覧を1ページで見て、使いたいツールへ移動するための入口ページです。
公開先（予定）：https://yu-ceo.github.io/ （リポジトリ `Yu-CEO.github.io`）

## できること
- 自己紹介（表示名・プロフィール文・TikTokへのボタン）を表示する
- ツール一覧のデータ（`js/tools_data.js`）から、ツールごとのカード（名前・一言説明・状態・開くボタン）を並べる
- 一覧のデータの形を検査し、正しくない項目は表示せず、ブラウザのコンソール（開発者用の画面）に理由を日本語で出す
- LINEのボタン2つ（メイン：オープンチャットに参加／サブ：LINEで友だち追加）を、設定ファイルのURLが正しいときだけ表示する
- ページ下部に、共通の注意書きを表示する

## 使い方
1. `index.html` をブラウザで開く（サーバー・インターネット接続は不要）
2. **ツールを増やすとき**：`js/tools_data.js` の配列に1件足す（`name`・`description`・`url`（`https://` で始まる）・`status`（`"公開中"` か `"準備中"`））。ほかのファイルは触らない
3. **LINE・TikTokのURLを変えるとき**：`js/site_config.js` の該当する1行を書き換える。空（`""`）にするとそのボタンは消える
4. **テスト**：このフォルダで `node --test`（Node.js 20 以上。外部ライブラリは不要）

## ファイルの地図
| ファイル | 役割 |
|---|---|
| `README.md` | このファイル。使い方の説明 |
| `index.html` | 画面の骨組み（自己紹介・一覧の場所・LINEボタンの場所・注意書き）と、下のファイルの読み込み |
| `css/style.css` | 見た目（おかね収支シミュレーターと同じ色。スマホ幅360pxで縦1列） |
| `js/site_config.js` | 設定値（LINEオープンチャット・LINE公式アカウント・TikTokのURL） |
| `js/tools_data.js` | ツール一覧のデータ。ツールを足すときはここだけ |
| `js/tools_validate.js` | 一覧データの形の検査（画面には触れない） |
| `js/tools_view.js` | 検査を通ったツールのカードを作って並べる。問題のある項目をコンソールに出す |
| `js/link_button.js` | URLが正しいときだけボタンを出す判定と切り替え（LINE・TikTok） |
| `js/main.js` | 入口。ページを開いたときに一覧の表示とボタンの切り替えを呼ぶだけ |
| `tests/tools_validate.test.js` | 検査のテスト（正しい例・name がない例・状態が違う例・`javascript:` のURLの例など） |
| `tests/tools_data.test.js` | 実際の `tools_data.js` の全項目が検査を通るかのテスト |
| `tests/tools_view.test.js` | カードの表示（公開中・準備中・0件）のテスト |
| `tests/link_button.test.js` | ボタンを出すかどうかの判定のテスト（空・`https://`・それ以外） |
| `docs/` | 開発用の資料（リポジトリには入らない） |
| `ci/confidential_check.py` | 機密チェック（GitHubに上げる前に、外に出せない情報がないか調べる） |
| `.github/workflows/ci.yml` | CI/CD の設定。GitHubに上げるたびにテストと機密チェックを自動で実行し、合格したら GitHub Pages に公開する（公開に入るのは `index.html`・`css/`・`js/` だけ） |
